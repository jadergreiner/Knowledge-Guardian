## Governance rule

Product artifacts must remain traceable:

```text
Problem → Outcome → Evidence → Decision → Roadmap → Backlog → Delivery → Metric → Learning
```

A backlog item without an identified problem or outcome should not enter delivery. A roadmap item without evidence must remain explicitly classified as a hypothesis or directional opportunity.
